# Страница интернет-магазина (Art Gallery)

Проект представляет собой макет интернет-магазина с функционалом поиска, добавлением товара в корзину и просмотра подробной информации о товаре.

## Технологии

- **Vue.js 2** (Options API)
- **Vue CLI / Webpack** (Сборка проекта)
- HTML5, CSS3 / SCSS (Адаптивная верстка, Flexbox/Grid)
- **Node.js**: v16 (Требование задания)

## Реализованный функционал

- [x] **Верстка**: Максимальное соответствие макету Figma.
- [x] **Адаптивность**: Корректное отображение до 360px.
- [x] **Поиск**: Живой поиск по названиям или автору картин. Лишние карточки скрываются при вводе.
- [x] **Кнопка "Купить"**: Имитация запроса (состояние "обрабатывается" с прелоадером на 2 секунды) с последующим переходом в состояние "в корзине".
- [x] **Сохранение состояния**: Использование `localStorage` для сохранения товаров в корзине при перезагрузке страницы.
- [x] **Модальное окно**: Открытие подробной карточки товара (описание, цена, слайдер на 2-4 изображения) по клику на картинку или название.

## Запуск проекта локально

**Важно:** Для корректной работы сборки убедитесь, что у вас установлена **Node.js версии 16**.

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера для разработки (с Hot-Reload)

```bash
npm run serve
```

После запуска приложение будет доступно по адресу `http://localhost:8080/` (или другому порту, указанному в консоли).

### 3. Сборка проекта для продакшена

```bash
npm run build
```
